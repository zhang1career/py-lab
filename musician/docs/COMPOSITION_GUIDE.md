# 旋律库作曲指南

本文档说明如何创作旋律，以及如何将五线谱音符转换为旋律库所需的数字表示。

---

## 一、旋律条目的参数结构

每支旋律是一个 JSON 对象，由以下可选顶层参数和必填的 `notes` 数组组成。

### 1.1 顶层参数（可选）

| 参数 | 类型 | 说明 |
|------|------|------|
| `key_root` | string \| number | 调根音。字符串如 `"d"`、`"c#"`（a～g 或 a#～g#）；或 MIDI 数字（0–127）。缺省时使用全局默认（如 C4=60） |
| `key_mode` | string | 调式：`"major"`（大调）或 `"minor"`（小调）。缺省为 `"major"` |
| `time_sign_numerator` | number | 拍号分子（如 4 表示 4/4 的 4） |
| `time_sign_denominator` | number | 拍号分母（如 4 表示 4/4 的 4） |
| `bpm` | number | 该旋律的 tempo（可选，部分实现支持） |
| `notes` | array | **必填**。音符数组，见下文 |

### 1.2 音符对象 `notes[]`

每个音符是一个对象，支持以下字段：

| 字段 | 简写 | 类型 | 说明 |
|------|------|------|------|
| `degree` | `d` | number | **音级（Scale Degree）**：1–7 表示本八度内，8–14 表示高八度，依此类推。详见第二节 |
| `duration` | `dur` | number | **时值（拍）**：以拍为单位。0.5=八分音符，1=四分音符，2=二分音符 |
| `velocity` | `vel` | number | **力度**：0–1，通常 0.75–0.9 |

**示例：**

```json
{
  "d": 1,
  "dur": 0.5,
  "vel": 0.84
}
```

等价于：

```json
{
  "degree": 1,
  "duration": 0.5,
  "velocity": 0.84
}
```

## 二、五线谱音符 → 数字的转换

旋律库使用**调内音级（scale degree）**，而不是绝对音高。因此需要先把五线谱上的音符翻译成音级数字。

### 2.1 音级数字 `d` 的含义

- **1** = 主音（do）
- **2** = 上主音（re）
- **3** = 中音（mi）
- **4** = 下属音（fa）
- **5** = 属音（sol）
- **6** = 下中音（la）
- **7** = 导音（si）

跨八度时，每高一个八度加 7：

- **8** = 高八度主音
- **9** = 高八度上主音
- **10** = 高八度中音
- …以此类推

负八度同理：**0** 或更小会映射到低八度，一般旋律中较少使用。

### 2.2 转换步骤

**第一步：确定调性**

根据五线谱调号或首尾和声确定调，例如：

- D 大调 → `key_root: "d"`, `key_mode: "major"`
- D 小调 → `key_root: "d"`, `key_mode: "minor"`

**第二步：将每个音符转为音级**

以 D 大调为例：

| 五线谱音名（D 大调） | 音级 `d` |
|---------------------|----------|
| D | 1 |
| E | 2 |
| F♯ | 3 |
| G | 4 |
| A | 5 |
| B | 6 |
| C♯ | 7 |
| D（高八度） | 8 |
| E（高八度） | 9 |
| … | … |

**通用规则：**

1. 找到调的主音（root）对应的音名。
2. 按大调或自然小调顺序数：1, 2, 3, 4, 5, 6, 7。
3. 每高一个八度，在原音级上加 7。

**大调音阶（按半音）：** 全-全-半-全-全-全-半  
**自然小调音阶：** 全-半-全-全-半-全-全  

**第三步：时值转换**

以四分音符为一拍（4/4 或 2/4 等常见情况）：

| 五线谱时值 | `dur` 值 |
|------------|----------|
| 全音符 | 4 |
| 二分音符 | 2 |
| 四分音符 | 1 |
| 八分音符 | 0.5 |
| 十六分音符 | 0.25 |
| 附点四分音符 | 1.5 |
| 附点八分音符 | 0.75 |

若以八分音符为一拍（如 6/8），则需按拍的单位重新换算。

**第四步：力度**

`vel` 一般在 0.75–0.9 之间，可根据强弱记号微调：

- **pp** → 0.5–0.6  
- **p** → 0.6–0.7  
- **mp** → 0.7–0.75  
- **mf** → 0.75–0.85  
- **f** → 0.85–0.95  
- **ff** → 0.95–1.0

## 三、完整示例

### 3.1 D 大调简单乐句

五线谱：D - E - F♯ - G - A - G - F♯ - E - D（每个音为四分音符）

```json
{
  "key_root": "d",
  "key_mode": "major",
  "notes": [
    {"d": 1, "dur": 1, "vel": 0.8},
    {"d": 2, "dur": 1, "vel": 0.8},
    {"d": 3, "dur": 1, "vel": 0.8},
    {"d": 4, "dur": 1, "vel": 0.8},
    {"d": 5, "dur": 1, "vel": 0.85},
    {"d": 4, "dur": 1, "vel": 0.8},
    {"d": 3, "dur": 1, "vel": 0.8},
    {"d": 2, "dur": 1, "vel": 0.8},
    {"d": 1, "dur": 1, "vel": 0.85}
  ]
}
```

### 3.2 含八分音符与高八度

五线谱：D - E - F♯（八分） - G（八分） - A（四分） - 高音 D（二分）

```json
{
  "key_root": "d",
  "key_mode": "major",
  "notes": [
    {"d": 1, "dur": 0.5, "vel": 0.8},
    {"d": 2, "dur": 0.5, "vel": 0.8},
    {"d": 3, "dur": 0.375, "vel": 0.78},
    {"d": 4, "dur": 0.375, "vel": 0.78},
    {"d": 5, "dur": 1, "vel": 0.85},
    {"d": 8, "dur": 2, "vel": 0.9}
  ]
}
```

### 3.3 D 小调旋律

D 自然小调：D E F G A B♭ C D

```json
{
  "key_root": "d",
  "key_mode": "minor",
  "notes": [
    {"d": 1, "dur": 0.5, "vel": 0.84},
    {"d": 2, "dur": 0.5, "vel": 0.8},
    {"d": 3, "dur": 0.5, "vel": 0.82},
    {"d": 4, "dur": 0.5, "vel": 0.78},
    {"d": 5, "dur": 1, "vel": 0.85},
    {"d": 1, "dur": 1, "vel": 0.8}
  ]
}
```

## 四、调根音与 MIDI 对照

`key_root` 使用音名字符串时，默认对应中央 C 所在八度（C4=60）：

| 音名 | 半音偏移 | MIDI（默认八度） |
|------|----------|------------------|
| c | 0 | 60 |
| c#, d♭ | 1 | 61 |
| d | 2 | 62 |
| d#, e♭ | 3 | 63 |
| e | 4 | 64 |
| f | 5 | 65 |
| f#, g♭ | 6 | 66 |
| g | 7 | 67 |
| g#, a♭ | 8 | 68 |
| a | 9 | 69 |
| a#, b♭ | 10 | 70 |
| b | 11 | 71 |

## 五、旋律表键名（lookup key）

`melody_table.json` 的键（如 `"1"`, `"2"`, `"3,4,5"`）用于根据运动轨迹的**音级序列**查找旋律。作曲时可直接在 `notes` 里写音符，不必关心这些键的匹配逻辑；键名主要用于程序内部的旋律查找。

## 七、快速对照表：五线谱 → 音级

**C 大调：** C=1, D=2, E=3, F=4, G=5, A=6, B=7  
**G 大调：** G=1, A=2, B=3, C=4, D=5, E=6, F♯=7  
**D 大调：** D=1, E=2, F♯=3, G=4, A=5, B=6, C♯=7  
**A 大调：** A=1, B=2, C♯=3, D=4, E=5, F♯=6, G♯=7  
**D 小调：** D=1, E=2, F=3, G=4, A=5, B♭=6, C=7  
**A 小调：** A=1, B=2, C=3, D=4, E=5, F=6, G=7  

其他调可按同样方式推导：先确定主音，再按音阶顺序编号 1–7，高八度加 7。
